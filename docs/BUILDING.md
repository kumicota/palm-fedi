# Building the Palm app

PalmFedi is a classic 68k Palm OS application (it runs under PACE on the
LifeDrive's ARM CPU, like nearly every Palm OS 5 app). It builds with:

* [prc-tools-remix](https://github.com/jichu4n/prc-tools-remix): GCC 2.95 for
  `m68k-palmos`, patched to build on modern Linux/macOS
* [PilRC](https://github.com/jichu4n/pilrc): resource compiler
* [Palm OS SDK 5r3](https://github.com/jichu4n/palm-os-sdk): headers and libraries

## Option A: prebuilt packages

prc-tools-remix and PilRC publish `.deb` packages on their GitHub release
pages. Install both, then install the SDK:

```sh
sudo git clone https://github.com/jichu4n/palm-os-sdk /opt/palmdev
sudo palmdev-prep -d sdk-5r3
```

## Option B: from source (what this repo was built with, Ubuntu 24.04)

```sh
sudo apt-get install build-essential autoconf automake libncurses-dev flex bison texinfo gperf

# compiler (m68k only is enough, which saves build time)
git clone --depth 1 https://github.com/jichu4n/prc-tools-remix
cd prc-tools-remix
sed -i 's/--enable-targets=m68k-palmos,arm-palmos/--enable-targets=m68k-palmos/; s/--enable-languages=c,c++/--enable-languages=c/' tools/build.sh
./tools/build.sh            # the final 'rm man7' cleanup step may fail; that's harmless
sudo cp -a dist/usr/. /usr/
cd ..

# resource compiler
git clone --depth 1 https://github.com/jichu4n/pilrc
cd pilrc/unix && autoreconf -fi && ./configure && make && sudo cp pilrc /usr/local/bin/
cd ../..

# SDK (use 5r3: the 5r4 headers in that repo have CRLF line endings that GCC 2.95 rejects)
git clone --depth 1 https://github.com/jichu4n/palm-os-sdk
sudo mkdir -p /opt/palmdev && sudo cp -a palm-os-sdk/sdk-5r3 /opt/palmdev/
sudo palmdev-prep -d sdk-5r3
```

## Build

```sh
make -C palm          # produces palm/PalmFedi.prc
```

Creator ID is `PFdi`. 68k code segments top out at 32 KB, so the app has two:
the main one (~26 KB: event loop, list, post view, drawing, networking) and
`dialogs` (~8 KB: preferences, login, compose, search, image viewer,
follow). `PalmFedi.def` declares them; functions marked `SEG_DIALOGS` go in
the second, and `m68k-palmos-multigen` generates the glue the Makefile links
in. Put new rarely-used code there too; `m68k-palmos-objdump -h
build/PalmFedi` shows how full each segment is.

## Icons

`palm/rsc/*.bmp` are generated by `palm/rsc/make_icons.py` (needs Pillow) and
are committed, so you only need to re-run it when the artwork changes.

## Testing without a device

* `make -C palm/tests` runs the record parser and URL encoder on the host
  (with ASan/UBSan).
* For the full app use an emulator: [CloudpilotEmu](https://cloudpilot-emu.github.io/)
  with a Palm OS 5 ROM (for example a Tungsten T3 or a Palm T|X ROM image
  you own), or POSE/Palm Simulator with the Palm OS 5 simulator. Point the
  app at your gateway's IP. In CloudpilotEmu, enable network proxying.
